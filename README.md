# จางวิท — ผู้ช่วยเสียงภาษาไทยบน Windows 11 และ Mac

จางวิทคือผู้ช่วยแบบ **J.A.R.V.I.S** ในหนัง ที่ฟังภาษาไทยรู้เรื่อง
แค่เรียก **"จางวิท"** แล้วพูดสิ่งที่อยากให้ทำ — ไม่ต้องกดปุ่ม ไม่ต้องพิมพ์ และคุยต่อได้เหมือนคุยกับเพื่อน

## ลองพูดแบบนี้

| พูดว่า | จางวิทจะ… |
|---|---|
| "จางวิท เปิดยูทูบ" | เปิด YouTube ใน Chrome ของคุณ |
| "จางวิท หยุดเพลงแล้วเปิดไลน์" | ทำสองอย่างต่อกันให้เลย |
| "จางวิท ตั้งเสียงไว้ที่สามสิบ" | ปรับเสียงเครื่องเป็น 30% |
| "จางวิท ราคาทองวันนี้เท่าไหร่" | ค้นในเว็บแล้วเล่าให้ฟัง |
| "จางวิท หาโรงแรมแถวเชียงใหม่ให้หน่อย" | เปิด Chrome หาให้ ระหว่างรอคุยเรื่องอื่นได้ |
| "จางวิท อ่านจอให้ฟังหน่อย" | อ่านสิ่งที่อยู่บนจอแล้วสรุปให้ฟัง |
| "จางวิท เปิดโน้ตแล้วสร้างโน้ตใหม่" | ขยับเมาส์ กดปุ่มให้ทีละขั้น |
| "จางวิท เหนื่อยจังเลย" | คุยเป็นเพื่อน |
| "จางวิท พอแล้ว" | หยุดพูด หรือยกเลิกงานที่ทำอยู่ |

- หลังคุยกันแล้ว **พูดต่อได้อีก 30 วินาทีโดยไม่ต้องเรียกชื่อซ้ำ**
- **พูดแทรก**ตอนจางวิทกำลังพูดได้ (มันจะหยุดฟังทันที)
- ถ้าคนในห้องคุยกันเองโดยไม่ได้เรียก "จางวิท" มันจะไม่ตอบ

## ทำงานยังไง

<p align="center"><img src="docs/images/flow.png" alt="ขั้นตอนการทำงานของจางวิท" width="100%"></p>

1. **ฟัง** — ไมค์ฟังตลอดเวลา ตัดเสียงของจางวิทเองออก (จึงพูดแทรกได้)
2. **ถอดเสียงเป็นข้อความ** — ใช้ตัวถอดเสียงภาษาไทยของ Apple ในเครื่อง (เร็ว ~0.1 วินาที ไม่ส่งเสียงออกไปไหน)
3. **ตัดสินใจด้วย Jev** — Jev คือ AI ตัดสินใจของ [TypeSafe](https://typesafe.ai) ที่ **เลือกคำตอบจากตัวเลือก**
   (เช่น "เป็นคำสั่งไหม" "เปิดแอปไหน" "คุยเล่นแบบไหน") ถามทุกอย่างในครั้งเดียว ใช้เวลา ~0.4 วินาที
   และบอกด้วยว่ามั่นใจแค่ไหน — **ถ้าไม่มั่นใจ จางวิทจะถามใหม่ ไม่เดาสุ่ม**
4. **ลงมือทำ** — สั่งเครื่อง / ตอบคุยเล่นทันที / ใช้ AI ในเครื่องตอบคำถาม / ค้นเว็บ / คุมเมาส์และคีย์บอร์ด
5. **ตอบด้วยเสียง** — เสียงผู้ชาย พูดเร็ว (ประโยคที่ใช้บ่อยเตรียมเสียงไว้ล่วงหน้า จึงตอบได้ทันที)

## หน้าจอ J.A.R.V.I.S

<p align="center"><img src="docs/images/states.png" alt="หน้าจอ J.A.R.V.I.S ในแต่ละสถานะ" width="100%"></p>

ลอยอยู่บนจอ ขยับตามเสียง และเปลี่ยนสีตามสิ่งที่จางวิทกำลังทำ
**ลากย้ายได้ · ดับเบิลคลิก = หยุด/เริ่มฟัง · คลิกขวา = เมนู** และมีไอคอนไมค์บนแถบเมนูด้านบนให้เปิด/ปิดการฟัง

## สิ่งที่ต้องมี

- **Windows 11** (หรือ **Mac ชิป Apple** M1 ขึ้นไป)
- **Python 3.10 ขึ้นไป**
- **คีย์ของ TypeSafe** (สำหรับ Jev) สมัครที่ [typesafe.ai](https://typesafe.ai) — ค่าใช้จ่ายราว 0.0002 ดอลลาร์ต่อประโยค
- **คีย์ของ Google Gemini หรือ OpenRouter** (สำหรับตอบคำถามและท่องเว็บด้วย `LLM_MODE=cloud` บน Windows หรือใช้ Ollama ในเครื่องได้)
- **Google Chrome** (สำหรับค้นเว็บ)

## ติดตั้งบน Windows 11 (ทำครั้งเดียว)

**1. ดาวน์โหลดโค้ด**

```powershell
git clone https://github.com/jaturapornchai/jarvisdemo001.git
cd jarvisdemo001
```

**2. สร้าง `.venv` และติดตั้งแพ็กเกจ** (หรือข้ามไปรัน `.\run_app.bat` ให้ติดตั้งอัตโนมัติก็ได้)

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

**3. ใส่คีย์** — คัดลอกไฟล์ตั้งค่า แล้วเปิด `.env` ใส่คีย์ `TYPESAFE_API_KEY=` และ `GOOGLE_API_KEY=` (หรือ `OPENROUTER_API_KEY=`)

```powershell
copy .env.example .env
```

**4. (แนะนำสำหรับอ่านจอภาษาไทย)** ติดตั้งชุดภาษาไทยใน Windows Settings › Time & language › Language & region › Add a language › **ไทย (Thai)** เพื่อให้ Windows OCR อ่านข้อความภาษาไทยบนจอได้

## เริ่มใช้งานบน Windows 11

```powershell
.\run_app.bat
```

หรือทดสอบระบบอ่านจอ เมาส์ คีย์บอร์ด และ UIAutomation (เปิดหน้าต่างทดสอบของตัวเอง ไม่แตะงานของคุณ):

```powershell
.\run_app.bat --selftest
```

## ติดตั้งบน macOS (ทำครั้งเดียว)

**1. ติดตั้งโปรแกรมที่ต้องใช้**

```bash
/opt/homebrew/bin/python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
```

**2. ติดตั้งเสียงภาษาไทย "Kanya"** (ถ้ายังไม่มี)
System Settings › Accessibility › Spoken Content › System Voice › Manage Voices… › ภาษาไทย › Kanya

**3. เปิดภาษาไทยสำหรับการถอดเสียง**
System Settings › Keyboard › Dictation › Languages › เพิ่มภาษาไทย

## เริ่มใช้งานบน macOS

```bash
./run_app.sh
```

จางวิทจะเปิดเป็นแอปชื่อ **Jarvis** พร้อมหน้าจอ J.A.R.V.I.S แล้วทักว่าพร้อมแล้ว
ปิดได้ด้วย **Ctrl+C** ในเทอร์มินัล หรือเมนู **ออก** ที่ไอคอนไมค์บนแถบเมนู/System Tray

### ให้สิทธิ์ครั้งแรก

macOS จะถามสิทธิ์ ให้กดอนุญาตแอป **Jarvis** (หรือเปิดเองที่ System Settings › Privacy & Security)

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| ไมโครโฟน (Microphone) | ฟังเสียงคุณ |
| Automation | สั่งเพลง โหมดมืด ปิดแอป |
| Accessibility | คลิกและพิมพ์ให้ |
| Screen & System Audio Recording | อ่านจอ — เปิดแล้วต้องปิดเปิดจางวิทใหม่หนึ่งรอบ |

ตรวจว่าใช้ได้ครบไหม (เปิดหน้าต่างทดสอบของตัวเอง ไม่แตะงานของคุณ):

```bash
./run_app.sh --selftest
```

## ปรับแต่ง (ไฟล์ `.env`)

| อยากได้ | ตั้งค่า |
|---|---|
| เปลี่ยนชื่อที่ใช้เรียก | `WAKE_WORD=จาร์วิส` |
| ไม่ต้องเรียกชื่อก่อนสั่ง | `WAKE_WORD=off` |
| พูดเร็วขึ้น/ช้าลง | `TTS_RATE=230` (ตัวเลขยิ่งมากยิ่งเร็ว) |
| เสียงทุ้มขึ้น/ปกติ | `TTS_PITCH=28` (เว้นว่าง = เสียงปกติ) |
| ให้ Chrome เปิดโปรไฟล์ที่ต้องการ | `CHROME_PROFILE=Default` |
| ใช้ AI บนคลาวด์ (ตอบฉลาดขึ้น) | `LLM_MODE=cloud` และใส่ `GOOGLE_API_KEY` หรือ `OPENROUTER_API_KEY` |
| ปิดหน้าจอ J.A.R.V.I.S | `HUD=off` |

ตัวเลือกทั้งหมดพร้อมคำอธิบายอยู่ใน [`.env.example`](.env.example)

## ความปลอดภัยและความเป็นส่วนตัว

- **เสียงของคุณไม่ถูกส่งออกจากเครื่อง** — ถอดเสียงในเครื่อง ส่งไปแค่ข้อความสั้นๆ ให้ Jev ตัดสินใจ
- **AI ตอบคำถามรันในเครื่อง** (ค่าเริ่มต้น)
- **Chrome ที่ใช้ค้นเว็บเป็นตัวแยก** ไม่ใช้บัญชีที่คุณล็อกอินไว้ (คำสั่ง "เปิด Chrome" จะเปิดตัวที่คุณใช้ประจำเสมอ)
- **ไม่ทำเรื่องเสี่ยงแทนคุณ**: ไม่กดปุ่ม ลบ / ส่ง / ซื้อ / จ่าย / ล้างถังขยะ / ไม่บันทึก, ไม่กรอกรหัสผ่าน,
  ไม่กด Enter ในแอปแชท — จะบอกให้คุณทำเอง
- **คนในห้องคุยกันเอง** ไม่ตอบ และไม่เก็บข้อความนั้นลง log
- ไฟล์ `.env` มีคีย์ลับ อย่าแชร์หรือ commit (`.gitignore` กันไว้ให้แล้ว)

## ปัญหาที่พบบ่อย

| อาการ | ลองทำแบบนี้ |
|---|---|
| ฟังไม่ค่อยรู้เรื่อง | เพิ่มระดับไมค์ที่ System Settings › Sound › Input (~75%) พูดใกล้ไมค์ขึ้น หรือใช้หูฟังที่มีไมค์ |
| อ่านจอ/คลิกไม่ได้ | เปิดสิทธิ์ให้ **Jarvis** แล้วปิดเปิดจางวิทใหม่ จากนั้นลอง `./run_app.sh --selftest` |
| เปิด Chrome แล้วขึ้นหน้าเลือกโปรไฟล์ | ตั้ง `CHROME_PROFILE=` เป็นชื่อโปรไฟล์ที่ใช้ประจำ |
| ไม่มีเสียงตอบ | ตรวจว่าติดตั้งเสียง Kanya แล้ว (`say -v Kanya สวัสดี`) |
| ตอบช้า | ดูบรรทัด `⏱ ตอบใน … ms` ใน log · ครั้งแรกใช้เวลาเตรียมเสียงสำเร็จรูป ~2 นาที |
